What is Dev Connect?

Dev Connect is a project from Quinton DEV. It provides a mobile application backed by our own API and supporting infrastructure, with features designed around developer tools and services.

We're building it as a small, independent project rather than a giant platform that needs to know everything about you. We try to collect only the information needed for the features we actually provide.

Google Sign-In

Dev Connect supports Google Sign-In so you can authenticate without giving Dev Connect your Google password. When you sign in, Google provides the basic account information we need to identify your account, such as your name, email address, email verification status and unique Google account identifier.

That information is used for authentication and account management. We don't sell Google account data or use it for advertising.

Built by a developer, not a marketing department

Dev Connect uses infrastructure such as Supabase for database storage and Google for authentication. Data is protected in transit using HTTPS/TLS, and Supabase provides encryption at rest for stored data.

We're keeping this website simple for now while the actual product develops. The proper design and portfolio will come later.
